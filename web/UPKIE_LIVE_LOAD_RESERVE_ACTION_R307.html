Authority boundary

MuJoCo provides causal wheel normal forces and plant state. Rust derives support geometry, filters signed load balance, predicts weakening reserve, advances DCM-guided lateral/bank requests, and slews one typed authority value. The ordinary floating WBC still owns torque admission. Python declares the immutable profile and scores the trace; it does not compute the action.

No promotion: delaying contact loss or passing a short recovery dwell is insufficient. Promotion requires a full five-second bilateral/upright tail, no body-ground stall, no non-admitted solve, hard residuals below 1e-8, and the existing timing/allocation gates.

Next architectural slice

The trace says the missing layer is contact-mode-aware reacquisition: an action that knows when preserving both wheels is no longer feasible, controls the single-support interval, and deliberately reloads the lost wheel. More QP iterations or a longer fall timeout would only hide the boundary.
